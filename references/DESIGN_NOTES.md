# Readay UI Redesign — Reference Design Notes

**Source:** Solace Reads (premium reading habit app)  
**Date:** 7 Nov 2026  
**Purpose:** Visual direction for UTS pitch deck + future redesign

---

## Design System Summary

### Color Palette
- **Background:** Cream/warm white (#F8F6F1)
- **Primary:** Deep forest green (#2C3E3A)
- **Accent:** Warm peach/salmon (#F4C5A0)
- **Text:** Charcoal black (#1A1A1A)
- **Supporting:** Soft beige, light tan, muted orange

### Typography
- **Display/Headers:** Modern serif (Freight/Tiempos-style) — high contrast, elegant
- **Body/UI:** Clean sans-serif (Inter/SF Pro-style)
- **Hierarchy:** Clear size differentiation (32-36pt → 11-12pt)

### Visual Language
- **Editorial, magazine-like layouts**
- **Generous whitespace (20-40px between sections)**
- **16-20px rounded corners**
- **Subtle shadows, no harsh drop shadows**
- **Warm, contemplative mood**

### Key Principles
1. **Premium lifestyle product** (not productivity tool)
2. **Literary DNA** (book covers, quotes, curated language)
3. **Restraint** (limited palette, purposeful spacing)
4. **Warmth** (analog-inspired colors, personal tone)
5. **Clarity** (clean information design despite rich functionality)

## Screen-by-Screen Notes

### 01 — Home Screen
- **Hero card:** Deep green "Tonight's Sanctuary" with featured book
- **Stats cards:** 2x1 grid (reading time, pages read)
- **Currently reading:** Horizontal carousel with book covers
- **Curated picks:** Editorial collections with ratings
- **Quote section:** Literary content break

**Key elements:**
- Personalized greeting ("Good Morning, Aisha")
- Date navigator (horizontal day selector)
- Progress toward daily goal
- CTA buttons in warm peach

---

### 02 — Journey/Analytics Screen
- **Achievement badge:** "Consistent Habit • Top 5%" (subtle celebration)
- **Primary goal card:** Semi-circular gauge (24/30 books, 80%)
- **Metric grid:** 2x2 stats (completed, pages, time, cadence)
- **Consistency heatmap:** Year-at-a-glance with 3-tone warmth
- **Genre resonance:** Horizontal bar chart (% + book count)
- **Recent milestones:** Chronological feed with book covers

**Key approach:**
- Stats as narrative ("Mindful enrichment", "Genre Resonance")
- Qualitative language (not "productivity goals")
- Holistic framing (journey, not dashboard)
- Subtle gamification (streak present but not dominating)

---

### 03 — Library/Queue Screen
- **Header:** "42 books saved" summary
- **Genre filters:** Horizontal pills (All, Fiction, Non-Fiction, Poetry)
- **Status tabs:** Now Reading (3) / Read Later (18) / Completed (21)
- **Book cards:** Cover + title/author + progress bar + last read timestamp
- **Search:** Top-right search icon

**Key patterns:**
- Clean book card template (reusable)
- Progress bars with percentage
- Contextual timestamps ("2d ago", "Last week")
- Light background (#F5F3EE) for secondary cards

---

### 04 — Reading Session Tracker
- **Hero card:** "Focus Ritual" with book + chapter context
- **Circular progress:** 28:45 / 45 min goal (peach arc)
- **Page tracker:** Current page + range + target
- **Ambient controls:** "Hearth" playing + alt options (Quiet Rain, Old Bistro, Wine in Pines)
- **Actions:** Pause / Jot Reflections / Finish & Log

**Key approach:**
- Deliberately minimal (no distractions)
- Target shown as reference (not countdown stress)
- Optional ambient sound (cozy ritual)
- Reflection capture integrated

## Design Differentiators (vs Typical Apps)

| Typical Reading Apps | Solace Reads Approach |
|---------------------|----------------------|
| Catalog-first (search) | Personalized queue-first |
| Productivity metrics | Mindful enrichment |
| Gamified streaks | Subtle habit recognition |
| Bright, aggressive UI | Warm, contemplative palette |
| Dashboard layout | Editorial magazine layout |
| Data-heavy | Data as narrative |
